# CactusRalph-Coder

A coding project and portfolio site by [AGI Corporation](https://github.com/AGI-Corporation), built with [Jekyll](https://jekyllrb.com/) and hosted on [GitHub Pages](https://pages.github.com/).

## Local Development

### Prerequisites

- Ruby ≥ 3.0
- Bundler (`gem install bundler`)

### Setup

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000> in your browser.

## Deployment

This site is automatically deployed to GitHub Pages via the included GitHub Actions workflow whenever changes are pushed to the `main` branch.
